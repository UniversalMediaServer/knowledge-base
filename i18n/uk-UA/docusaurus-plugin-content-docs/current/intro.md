# Вступ

Цей сайт містить офіційну документацію з використання Universal Media Server (UMS).

Якщо ви ще не є користувачем і плануєте завантажити програму або визначаєтесь, чи варто її використовувати, вам, ймовірно, буде кориснішим [наш головний вебсайт](https://www.universalmediaserver.com).

Він розділений на 3 основні розділи: налаштувань, посібників та встановлення.

Якщо ви завітали сюди в пошуках конкретної інформації, якої не знайшли, будь ласка, повідомте нам про це за допомогою GitHub, щоб ми могли її додати.
